# GWAS Analysis of Coronary Artery Disease (CAD) — PennCATH Cohort

Полногеномный поиск ассоциаций (GWAS) для выявления генетических вариантов, связанных с ишемической болезнью сердца, с полным циклом обработки данных: QC, импутация, анализ популяционной структуры и биологическая интерпретация результатов.

## Основные этапы

### 1. Контроль качества и фильтрация

- Удалены SNP с долей пропусков более 50%.
- Фильтрация по редким аллелям (MAF < 0.05), так как редкие варианты часто являются шумом и требуют больших выборок для обнаружения ассоциаций.
- Фильтрация по отклонению от равновесия Харди-Вайнберга (p < 1e-6) для исключения ошибок генотипирования.
- Образцы с аномальной гетерозиготностью не обнаружены.

### 2. Импутация пропущенных генотипов

- 79.89% всех SNP содержали пропуски, что недопустимо для регрессионного анализа.
- Применена импутация по моде (замена NA наиболее частым генотипом в выборке).

### 3. Анализ популяционной структуры

- Выполнен PCA-анализ через SVD-разложение для выявления скрытой популяционной стратификации, способной вызвать ложные ассоциации.
- Scree plot показал явный перегиб на 4–5 компонентах, которые объясняют большую часть дисперсии.
- PCA plot по первым двум компонентам выявил 3 генетических кластера, однако они не коррелируют с полом или фенотипом.
- Первые 5 главных компонент включены как коварианты в модель.

### 4. GWAS-анализ

- Модель: логистическая регрессия с включением пола, возраста и 5 главных компонент как ковариант.
- Для каждого SNP рассчитаны β, SE, Z-score, χ²-статистика, P-value и отношение шансов (OR).
- QQ-plot и коэффициент геномной инфляции (λ ≈ 1.0) подтверждают отсутствие систематических смещений.

## Результаты

- Genome-wide значимость (p < 5×10⁻⁸): 11 SNP.
- Предположительные ассоциации (p < 5×10⁻⁶): 14 SNP.
- Наиболее значимый SNP: rs1778596, p ≈ 4.88×10⁻²⁵, хромосома 1.
- Максимальный OR: 12.98.

Анализ генов в идентифицированных локусах:

| SNP | Ген / Локус | Связь с CAD |
|---|---|---|
| rs1778596 | PDE4D | Гидролиз цАМФ, регуляция сосудистого тонуса, ассоциация с инсультом и атеросклерозом |
| rs12741415 | IL6R | Рецептор интерлейкина-6, медиатор воспаления, продукция CRP |
| Топ-снипы chr9 | 9p21.3 | Наиболее известный локус риска CAD (подтверждён в Arteriosclerosis, Thrombosis, and Vascular Biology, 2025) |

## Ключевые компетенции

- Полный цикл GWAS-пайплайна: от QC и фильтрации до биологической интерпретации результатов.
- Статистическое моделирование: логистическая регрессия, коррекция на множественные сравнения (genome-wide threshold 5×10⁻⁸), расчёт геномной инфляции.
- Анализ популяционной структуры: PCA, SVD, идентификация скрытых подгрупп для контроля confounding-эффектов.
- Биоинформатическая интерпретация: аннотация SNP и поиск биологического смысла в научной литературе.
