# Polygenic Risk Score (PRS) for Coronary Artery Disease

Построение и валидация полигенной оценки риска ишемической болезни сердца на основе GWAS-статистик с полным циклом контроля качества, расчёта PRS и оценки предсказательной способности.

## Цель

Построить полигенную оценку риска (PRS) для ишемической болезни сердца, оценить её предсказательную способность на независимой валидационной выборке и продемонстрировать полный пайплайн работы с генетическими данными: от контроля качества до интерпретации результатов.

## Основные этапы

### 1. Контроль качества целевых данных

- Удаление дубликатов rsID.
- Прунинг по LD и расчёт гетерозиготности.
- Исключение образцов с аномальной гетерозиготностью.
- Оценка попарного родства и удаление родственников с PI_HAT > 0.125.

### 2. Гармонизация базовых и целевых данных

- Strand flipping.
- Recoding.
- Исключение несовпадающих аллелей.

### 3. Разделение на обучающую и валидационную выборки

### 4. Расчёт главных компонент

- PCA выполнен на LD-pruned SNP.
- По scree plot отобраны первые 7 главных компонент, объясняющих наибольшую долю генетической дисперсии.
- Компоненты включены как коварианты для контроля популяционной стратификации, совместно с полом и возрастом.

### 5. Расчёт PRS

- Инструмент: PRSice-2.
- Оптимальный порог p-value для включения SNP в PRS: 0.4762 (202849 SNP).
- Обучение модели на тренировочной выборке, затем применение весов на валидационной.

### 6. Оценка предсказательной способности

| Метрика | Обучающая выборка | Валидационная выборка |
|---|---|---|
| P-value PRS | 5.36×10⁻³⁴ | 4×10⁻¹⁴ |
| Nagelkerke R² | 0.511 | 0.543 |
| ROC AUC | 0.811 | 0.812 |
| OR | ∞ | ∞ |

- PRS значимо ассоциирован с CAD на обеих выборках (p < 0.05).
- Распределение PRS у случаев сдвинуто вправо относительно контролей, что подтверждает ассоциацию высокого PRS с наличием заболевания.
- Анализ различных порогов p-value показал максимум R² при пороге 0.4762, что соответствует оптимальному балансу между включением сигналов и исключением шума.

## Результаты и интерпретация

PRS демонстрирует высокую предсказательную способность (R² ≈ 0.51–0.54, AUC ≈ 0.81). Метрики практически идентичны на обучающей и валидационной выборках, что исключает классическое переобучение.

## Ключевые компетенции

- Полный пайплайн построения PRS: QC, гармонизация данных, расчёт, валидация.
- Работа с PLINK и PRSice-2 для обработки крупномасштабных генетических данных.
- Контроль популяционной стратификации через PCA и включение главных компонент как ковариант.
- Оценка предсказательной способности модели: Nagelkerke R², ROC AUC, сравнение распределений PRS.
- Критическая интерпретация результатов и выявление потенциальных источников смещения.
